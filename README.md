# Projektvorschläge

Dieses Repository enthält **Projektideen für individuelle Praxis- und Referenzprojekte** während der Ausbildung.

Die Vorschläge richten sich an Teilnehmer, die zusätzlich oder ergänzend zu ihrem persönlichen Lernpfad ein eigenes Projekt umsetzen möchten.

## Projektideen

Die einzelnen Projektvorschläge werden als **GitHub Issues** verwaltet.

Jeder Vorschlag beschreibt eine mögliche Projektidee und kann unter anderem folgende Informationen enthalten:

- Projekttitel
- kurze Beschreibung
- Ziel des Projekts
- mögliche Zielgruppe
- möglicher Tech Stack
- Schwierigkeitsgrad
- empfohlener Zeitraum
- mögliche Lernziele
- MVP / Kernfunktionen
- optionale Erweiterungen

## Technologie

Die angegebenen Technologien sind als **Vorschlag** zu verstehen.

Je nach Lernziel kann ein Projekt auch mit einem anderen Tech Stack umgesetzt oder angepasst werden.

Mögliche Schwerpunkte sind zum Beispiel:

- Python
- Web Development
- Next.js
- React
- Flutter / Dart
- Kotlin
- Swift / IOS
- Spring
- AI
- AI Agents
- APIs
- Datenbanken
- Testing
- Full-Stack Development
- oder auch alle möglichen Kombinationen

## Eigene Projektideen

Die vorhandenen Vorschläge dienen als Inspiration.

Eigene Projektideen sind ausdrücklich möglich. Ein bestehender Vorschlag kann außerdem verändert, erweitert oder auf die eigenen Lernziele angepasst werden.

## Ziel der Projektvorschläge

Die Projekte sollen einen Rahmen bieten, um Technologien praktisch anzuwenden und ein zusammenhängendes Softwareprojekt umzusetzen.

Dabei steht nicht ein bestimmter Tech Stack im Vordergrund, sondern die Möglichkeit, ein Projekt passend zu den eigenen Interessen und Lernzielen auszuwählen.
